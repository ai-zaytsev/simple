# Plan: Retire A Node

## Порядок

1. Найти машину у провайдера по имени.
2. Снять ноду с выдачи и освободить домен — до удаления.
3. Удалить машину формой, которая уже проверена.
4. Убедиться, что её нет в списке.

## Риски

**Выдавать несуществующую ноду.** Строка помечается удалённой раньше машины.

**Замена окажется невозможна.** Домен освобождается той же транзакцией.

**Удаление «прошло», а машина работает.** Провайдер уже так делал. Итог судится по списку, а не по коду ответа.

**Остаться с одной нодой.** Так и будет между шагами, и это принято: один пользователь, потеря связи некритична.

## Валидация

- список у провайдера после удаления
- `Add Server` принимает освобождённый домен
