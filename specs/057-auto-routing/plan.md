# Plan: Auto Routing

1. Таблица правил, план несёт пять списков и переключатель.
2. Клиент строит правила движка в фиксированном порядке.
3. Приложения «напрямую» исключаются из туннеля.
4. DNS по маршруту.
5. Определение «сеть уже идёт через нашу ноду».
6. Workflow правил с проверкой формы.
7. Тесты порядка и разбора без устройства.
8. Проверка конфигурации раньше, когда приложение выводят на экран.

## Риск

Правило с сервера попадает в конфигурацию движка. Ошибка формы роняет туннель у всех, кто заберёт следующий план, поэтому форма проверяется до записи, а не при применении.
