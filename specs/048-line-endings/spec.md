# Spec: Line Endings

Возврат каретки доехал до ноды внутри shebang, и ядро искало интерпретатор с именем `python3\r`.

## Что Произошло

Агент лежит в репозитории, репозиторий выложен на Windows, git при выкладке превращает переводы строк в CRLF. Файл скопировали на Linux-машину как есть. В самом файле не было ничего неправильного — неправильной была выкладка.

Ошибка выглядела так, будто на ноде не установлен Python. Он установлен.

## Почему Это Не Одноразовая Оплошность

Она повторится при каждом следующем чекауте на Windows и в каждом файле, который выкладывается на Linux-машину копированием. Чинить её на месте — значит чинить её каждый раз.

`.gitattributes` фиксирует переводы строк для расширений, которые исполняются на Linux: `.sh`, `.py`, `.sql`, `.yml`, `.yaml`. После этого рабочая копия на Windows содержит LF в этих файлах, и копировать можно что угодно чем угодно.
