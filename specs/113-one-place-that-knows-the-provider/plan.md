# Plan: One Place That Knows The Provider

## Порядок

1. Собрать в один файл то, что уже добыто запусками.
2. Перевести на него `retire-node.yml` — тот, где ошибка и случилась.
3. Записать остальные два в долг.

## Риски

**Переписать всё сразу посреди работы.** `add-node.yml` понадобится через несколько минут; менять его сейчас значит менять инструмент, которым работаешь.

**Общий файл станет ещё одним местом, а не единственным.** Поэтому долг записан с условием закрытия, а не с намерением.

## Валидация

- живой запуск `Retire Node` доходит до удаления
