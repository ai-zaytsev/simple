# Plan: Копии, которые можно восстановить

## Порядок

1. Получатели в репозитории, не меньше двух, проверяются перед снятием копии.
2. Дамп по SSH через `age` в файл, без открытого текста на диске.
3. Загрузка в `db/` без ACL, с чтением обратно.
4. Проверка baseline: `db/` и публичный ACL несовместимы.
5. Репетиция восстановления во временную базу, вручную и через Environment.
6. Выкат Core зависит от свежей копии.

## Риски

**Публичный дамп.** Один флаг отделяет его от APK. Закрыто проверкой, испытанной подделкой: строку с публичным ACL и префиксом `db/` добавили — проверка её нашла.

**Копия, которую нечем открыть.** Один получатель — одна потеря. Минимум два проверяются до снятия.

**Пустая копия, выглядящая целой.** `pipefail` при снятии и подсчёт содержимого при восстановлении; «применилось без ошибок» ответом не считается.

**Конвейер читает бэкапы.** Не читает: закрытых ключей владельца в CI нет. Ключ репетиции — третий и заперт за одобрением.

**Закрытый ключ окажется в репозитории.** `.gitignore` отвергает `*.key`, `*.p12`, `*.age`. Это последняя сетка, а не основная защита: ключи живут вне рабочего каталога.

**Выкат заблокирован отсутствием ключей.** Это плата за порядок «сначала копия», и она названа явно, а не обнаружится при первом выкате.

## Валидация

Проверка приватности испытана подделкой. Настоящая проверка — первый живой прогон: копия снята, прочитана обратно, затем репетиция восстановления считает аккаунты и связи.
