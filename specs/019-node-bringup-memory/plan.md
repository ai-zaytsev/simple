# Plan: Node Bring-up Memory And Visibility

- Feature ID: `019-node-bringup-memory`
- Feature Branch: `feature/019-node-bringup-memory`
- Owner: `orchestrator`

## Implementation Slices

1. Swap до установки пакетов.
2. Временный сервер статуса на время bring-up.
3. Явное ожидание пакетов и остановка при их отсутствии.
4. Остановка при неверной конфигурации Nginx.
5. Прогон.

## Risks

- временный сервер статуса занимает порт 80 и должен быть снят до старта Nginx: снятие выполняется по сохранённому pid
- сервер статуса включается только на проверочных нодах: в проде он описывал бы наш bring-up любому желающему
- если памяти не хватит даже со swap, следующий шаг — заменить Certbot на однобинарный ACME-клиент, что убирает питоновский стек целиком

## Validation Plan

- рендер шаблона локально, проверка YAML и разбор ключей cloud-config
- прогон с уборкой
