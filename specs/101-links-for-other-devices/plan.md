# Plan: Links For Other Devices

## Порядок

1. Вид и название у строки устройства; отдельный лимит на тариф.
2. Выселение перестаёт считать внешние устройства.
3. Сборка ссылки — чистая функция, проверяемая без базы и без сети.
4. Добавление внешнего устройства; отзыв и список переиспользуются.

## Риски

**Телевизор выселит телефон.** При `max_devices = 1` это произошло бы первым же добавлением. Выселение сужено до `kind = 'app'` раньше, чем появилась возможность добавить внешнее устройство.

**Общий ключ.** Учётка привязана к строке устройства уникальным индексом, так что общего ключа негде держать. Отдельная таблица для внешних устройств создала бы второй путь отзыва — не заводится.

**Ссылка не заработает в чужом клиенте.** Формат проверяется разбором обратно: собранная ссылка парсится и сверяется по каждому параметру, включая экранирование пути.

**FREE получит внешние устройства.** Лимит ноль, отказ до записи.

## Валидация

- разбор собранной ссылки обратно, включая путь с косой чертой и название с пробелами
- отказ для тарифа без внешних устройств
- живая: телевизор, роутер, отзыв телевизора, роутер работает
