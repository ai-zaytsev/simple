# Plan: Ephemeral Test Node

- Feature ID: `014-test-node`
- Feature Branch: `feature/014-test-node`
- Owner: `orchestrator`

## Implementation Slices

1. Ресурс ноды в Terraform, выключенный по умолчанию, с предусловием на наличие credential.
2. cloud-init: установка Xray закреплённой версии с проверкой контрольной суммы, конфигурация без access log.
3. Workflow: генерация credential, создание, ожидание готовности, проверка прохода трафика, уничтожение.
4. Подтверждение отсутствия дроплетов запросом к провайдеру.

## Risks

- cloud-init может не успеть до таймаута ожидания: опрос порта вместо фиксированной паузы
- release digest от того же издателя, что и артефакт: ловит повреждение загрузки, но не подмену издателем
- уничтожение может не сработать: поэтому после него идёт независимая проверка через API провайдера, а не доверие отчёту Terraform
- `keep_node` оставляет ноду под тарификацией: об этом печатается предупреждение в отчёт

## Validation Plan

- локальная проверка YAML и форматирования Terraform
- прогон с уничтожением
- сверка числа дроплетов после прогона

## Merge Readiness

Задача закрывается, когда прогон подтвердил проход трафика и отсутствие оставшихся ресурсов.
