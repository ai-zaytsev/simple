# Plan: No Addresses In A Public Log

## Порядок

1. Найти, где адрес становится step output.
2. Маскировать до записи.
3. Переписать сообщения.
4. Проверка в baseline, испытанная в обе стороны.

## Риски

**Маска не покроет ранние строки.** `::add-mask::` действует вперёд, поэтому ставится сразу после вычисления и до любой записи.

**Проверка поймает не то.** Ищутся только публикации вывода, чьё имя про адрес; маска сопоставляется той же переменной, а не любой.

## Валидация

- с убранной маской проверка падает и называет файл и строку
- с маской проходит
