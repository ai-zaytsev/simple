# Plan: Network Change Debounce

1. Отложить перезапуск на короткий интервал.
2. Каждая новая смена отменяет отложенный перезапуск и планирует его заново.
3. Отменять отложенный перезапуск при остановке туннеля, чтобы он не сработал после teardown.

## Риски

- Слишком долгая задержка удлиняет время, в течение которого трафик идёт через мёртвые сокеты. Слишком короткая не склеивает ничего. Интервал выбран в несколько секунд: смены при переходе между сетями приходят пачкой за секунду-две.
