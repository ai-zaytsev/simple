# Plan: Sign In

1. Схема: адрес у аккаунта, таблица попыток входа.
2. Отправка письма через существующего провайдера, только текстом.
3. Три обработчика: начать, опросить, подтвердить.
4. Клиент: экран адреса, ожидание, повтор, смена адреса.
5. Выдача плана только подтверждённому устройству.

## Риск

Ссылка ведёт на домен Control Plane, значит этот домен попадает в письма и виден почтовым системам. Альтернатива — домен сайта — хуже: он рекламируется и будет заблокирован раньше, а тогда вход перестанет работать. Зафиксировать как принятый размен.
