# Plan: Compare Like With Like

## Порядок

1. Посмотреть на панель после выката, а не считать выкат завершением.
2. Найти, откуда взялась разница в пять раз между одинаковыми машинами.
3. Заменить абсолютный порог сравнением с парком.
4. Закрепить тестом настоящее число с живого устройства.

## Риски

**Самокалибровка скрывает общую деградацию.** Если медленны все, никто не наказан. Принято сознательно: выбиратель отвечает на вопрос «какую из этих», а состояние парка целиком показывает панель.

**Медиана по двум нодам.** При двух измеренных нодах медиана — верхняя из них. На малом парке точность невелика, и это лучше, чем порог, выбранный наугад.

## Валидация

- Тест с настоящим числом: 535 мс рукопожатия против непроверенной ноды.
- Тест на относительность: вдвое дороже — хуже; одинаково медленные — поровну.
- Панель после выката: проверить, что оценки сравнялись.
