# Spec: Инвентаризация системы для Business Owner

- Feature ID: `158-business-owner-inventory`
- Feature Branch: `feature/158-business-owner-inventory`
- Status: `merge-ready`

## Goal

Создать один актуальный операционный документ, по которому Business Owner понимает работу приложения, состав и размещение инфраструктуры, мониторинг, типовые отказы, восстановление и действия при росте нагрузки.

## Acceptance Criteria

- Один BO-документ охватывает приложение, инфраструктуру, мониторинг, отказы, восстановление и масштабирование.
- Для каждого операционного компонента указаны назначение, провайдер, регион, домен, зависимости и последствия отказа.
- Для каждого управляемого узла есть мини-инструкция: проверка, перезапуск, логи, отказ и восстановление.
- Секреты и секретные значения в документ не попадают.
- Дублирующая BO-информация удалена, а старые места при необходимости содержат только ссылку на единый источник истины.
- Уникальная техническая документация разработчиков сохранена.
- По репозиторию не остаётся известных противоречащих друг другу операционных инструкций.

## Non-Goals

- Изменение инфраструктуры или runtime-кода.
- Ротация секретов.
- Создание новых панелей мониторинга.
- Замена технических runbook и архитектурных документов для разработчиков.
