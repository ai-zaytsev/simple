# Plan: Android VPN Vertical Slice

- Feature ID: `012-android-vertical-slice`
- Feature Branch: `feature/012-android-vertical-slice`
- Owner: `orchestrator`

## Implementation Slices

1. Каркас проекта с закреплёнными версиями.
2. Сервис, состояние, жизненный цикл, реакция на смену сети.
3. Создание TUN с защитой от петли и от утечки IPv6.
4. Генерация конфигурации движка и маршрутизация двумя уровнями.
5. Интерфейс из одной кнопки и честного статуса.
6. Сборка APK в CI и сборка движка из исходников.
7. Привязка движка по фактической сигнатуре AAR.
8. Проверка на устройстве.

Шаги 7 и 8 не выполнены: первый ждёт сигнатуру AAR, второй ждёт endpoint.

## Risks

- `foregroundServiceType=specialUse` для VPN не проверен на устройстве с Android 14: у Android нет выделенного типа для VPN
- MTU 1500 выбран как типовой, при инкапсуляции возможна фрагментация; проверяется на реальном соединении
- перезапуск движка при смене сети может оказаться избыточным, если движок восстанавливает сокеты сам: уточняется после привязки
- стартовые списки маршрутизации составлены по общеизвестным сервисам, а не по измерению

## Validation Plan

- сборка APK в CI, запись SHA-256
- запуск `libXray Build`, получение публичной сигнатуры и версии Xray-core
- ручная проверка на устройстве: ON, OFF, закрытие Activity, переключение сети, проверка на утечку DNS

## Merge Readiness

Слайс закрывается после привязки движка и подтверждённого соединения на устройстве. Текущий PR даёт всё, кроме этих двух шагов.
