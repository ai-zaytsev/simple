# Plan: Engine Binding

- Feature ID: `030-engine-binding`
- Feature Branch: `feature/030-engine-binding`
- Owner: `orchestrator`

## Implementation Slices

1. Извлечь контракт управления движком из исходников закреплённой версии.
2. Написать привязку с проверкой ответа и закрытым перечнем команд.
3. Подключить защиту сокетов.
4. Встроить сборку AAR в сборку приложения с кэшем по коммиту.
5. Сборка APK.

## Risks

- версия контракта проверяется движком: несовпадение с вложенным AAR даёт отказ в работе, поэтому версия закреплена рядом с коммитом
- первая сборка после смены версии движка длинная: последующие берут AAR из кэша
- размер APK вырастет: движок содержит нативные библиотеки

## Validation Plan

- сборка APK в CI, отчёт показывает наличие движка

## Merge Readiness

Закрывается зелёной сборкой APK с вложенным движком.
