# Plan: Add A Server In One Operation

## Порядок

1. Проверить, чего не хватает из доступов и доменов — оказалось, ничего.
2. Снять образец с ноды, которая уже работает, вместо сочинения конфигурации.
3. Скрипт, доводящий голую машину до базового состояния.
4. Выбор удостоверяющего центра на уровне ноды.
5. Операция, связывающая шаги и двигающая состояния.

## Риски

**Домен уже занят.** Прогон отказывается в самом начале: указать DNS занятого домена на новую машину значит отключить людей, работающих через старую, и отчитаться об успехе.

**Машина создана, прогон упал.** Итог всегда называет имя машины у провайдера и то, чем её убрать. Оплата почасовая, и забытая машина тратит деньги тихо.

**Секрет ноды в логе.** Маскируется сразу после создания, передаётся один раз по ssh и в окружении, а не аргументом: список аргументов виден любому процессу на машине.

**Расхождение логики DNS.** Вынесена в один скрипт, вызываемый обеими операциями.

**Тестовая нода получает настоящий сертификат.** Проверка требует совпадения центра с заказанным.

## Валидация

Настоящая проверка — прогон на живой машине с тестовыми сертификатами: он ничего не тратит из настоящей квоты и стоит несколько центов почасовой оплаты. Решение о создании машины принимает человек, поэтому прогон запрашивается, а не делается молча.
