# Spec: Kamatera Secrets

## Что Случилось

Шаг создания машины печатал ответ API целиком, «чтобы посмотреть, что пришло». Провайдер вложил в этот ответ сгенерированный пароль root, и пароль оказался в публичном логе сборки.

Вторым дефектом того же прогона удаление машины сообщило об успехе, ничего не удалив: пустой ответ, машина работает, шаг зелёный.

## Цель

Сделать невозможным первое и заметным второе.

## Scope

- ответ внешнего API не печатается целиком нигде
- при неизвестной форме ответа печатается набор имён полей, без значений
- пароль маскируется сразу после получения, до любого другого действия
- удаление судится по коду ответа, а не по факту возврата вызова
- исправлен разбор статуса очереди
- адреса машин печатаются: они нужны и не секретны

## Вне Scope

- ротация ключей провайдера: они не попадали в лог, GitHub их маскирует
- удаление истории прогона: это действие Business Owner в интерфейсе GitHub

## Критерий

Ни один шаг не печатает тело ответа. Выжившая после удаления машина завершает прогон ошибкой со словами о деньгах.
