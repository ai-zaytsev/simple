# Plan: A Removed Node Is Not A Silent One

## Порядок

1. Исключить удалённые из таблицы здоровья.
2. Проверить, что таблица жизненного цикла их сохраняет.

## Риски

**Спрятать ноду, которая на самом деле сломалась.** Исключаются только `removed` — состояние, которое ставится намеренно при сносе, а не выводится из измерений.
