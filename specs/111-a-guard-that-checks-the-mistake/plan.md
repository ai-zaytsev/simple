# Plan: A Guard That Checks The Mistake

## Порядок

1. Расширить проверку со «шага вывода» до «всего, что печатает».
2. Посмотреть, что она найдёт.
3. Закрыть найденное; законное пометить причиной.
4. Испытать в обе стороны.

## Риски

**Слепая маскировка сломает полезное.** Ответ DNS-проверки замаскировать значит оставить проверку, которая ничего не проверяет. Отсюда исключение с причиной.

**Проверка снова окажется уже ошибки.** Поэтому она смотрит на способ показать, а не на конкретную конструкцию.

## Валидация

- с убранной маской падает и называет файл и строку
- законный случай проходит по пометке
