# Plan: Node Endpoints Answer Only Nodes

## Порядок

1. Посмотреть, что домен отвечает на служебные пути.
2. Ограничить их адресами из таблицы нод.
3. Превратить отказ в обычный 404.
4. Починить то, что этим ломается: рождение и снятие ноды.

## Риски

**Закрыть доступ работающим нодам.** Проверено сразу после применения: обе забирают список и принимаются с отчётами.

**Пустой список запирает всех.** Скрипт отказывается писать список без адресов.

**Сломать наблюдаемость.** Эндпоинты устройств лежат под другим префиксом и не затронуты; проверено из интернета.

**Новая нода родится запертой.** Операция добавления обновляет список сразу после того, как узнала адрес машины.

## Валидация

Из интернета: три пути дают 404, неотличимый от любого несуществующего. С нод: 200 и 200. Замеры продолжают приходить.
