# Plan: Central Certificates

1. Проверить, что TXT-запись пишется, отдаётся и убирается у обоих регистраторов.
2. Выпуск по CSR на Control Plane, DNS-01, ключ остаётся на ноде.
3. Учёт выпусков против предела Let's Encrypt.
4. Продление на ноде: ежедневная проверка, запрос только при приближении срока.
5. Убрать HTTP-01 с боевых нод.

## Риск

Ошибка в выпуске оставляет ноду с истёкшим сертификатом, то есть без туннеля. Поэтому первым шагом проверяется способность записать запись, а не строится всё сразу.
