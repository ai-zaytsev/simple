# Spec: Survive A Dropped Connection

Третий живой прогон упал на первом же шаге: оборвалось SSH-соединение с хостом Control Plane.

## Что Известно О Причине

Хост в этот момент был совершенно здоров: нагрузка ноль, занято 158 МБ из 957, событий OOM нет, ограничений sshd нет (`maxstartups 10:30:100`, `persourcemaxstartups none`), отказов в его собственных логах нет.

За один день соединение с этим хостом обрывалось трижды: дважды из GitHub Actions и один раз с рабочей машины. Рвётся сеть по пути, а не сервер.

## Что Изменено

Операция из восьми шагов по SSH не должна решаться самой ненадёжной секундой дня. Введена обёртка, повторяющая вызов при обрыве соединения.

Повтор только при коде 255 — им ssh сообщает о собственном отказе, то есть команда, возможно, не выполнялась. Любой другой код пришёл с той стороны и является ответом: повторять его значит выполнить изменение дважды.

Ввод для удалённой команды называется явно, файлом. Первая версия читала стандартный ввод и буферизовала его — и повисла в первом же месте, где ввод был открытой трубой, которую никто не собирался закрывать. Явный ввод к тому же переживает повтор: heredoc, съеденный первой попыткой, во второй отправил бы пустоту и отчитался об успехе.

Копирование файлов защищено тем же правилом: `scp` отказывает так же и по той же причине.

## Проверено В Четыре Стороны

| случай | ожидание | результат |
| --- | --- | --- |
| обычная команда | проходит | проходит |
| ввод из файла | доходит до удалённой команды | доходит |
| отказ на той стороне | без повтора, код сохранён | код 7 сохранён |
| недостижимый хост | повторяет и сдаётся | три попытки, код 255 |
| копирование через обёртку | доставляет файл | доставляет |

## Что Не Тронуто

Цикл ожидания новой машины оставлен без обёртки: он и должен отказывать раз за разом, пока машина поднимается, и у него свой счётчик.

Операция выката Control Plane страдает тем же — один её прогон сегодня оборвался ровно так же и оставил работать прежний бинарь. Лечится тем же приёмом; записано отдельно, чтобы не менять путь выката во время незакрытой стадии.
