# Plan: Survive A Dropped Connection

## Порядок

1. Убедиться, что дело не в хосте.
2. Обёртка с повтором только для обрыва.
3. Проверить в четыре стороны.
4. Применить ко всем удалённым вызовам операции, кроме того, что обязан отказывать.

## Риски

**Повтор выполняет изменение дважды.** Повторяется только код 255 — собственный отказ ssh. Ответ с той стороны не повторяется никогда.

**Повтор отправляет пустоту.** Ввод — файл, а не поток: он переживает попытку.

**Обёртка виснет.** Первая версия висла на незакрытом вводе. Ввод стал явным, и висеть больше не на чем.

## Валидация

Четыре случая проверены на живом хосте, включая недостижимый адрес.
