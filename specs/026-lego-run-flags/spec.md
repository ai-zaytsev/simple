# Spec: ACME Flags Belong To Run

- Feature ID: `026-lego-run-flags`
- Feature Branch: `feature/026-lego-run-flags`
- Status: `in-progress`

## Причина

В lego v5 глобальными остались только help, version, логирование и config. Всё остальное принадлежит подкоманде. Подтверждено исходником v5.4.0: `run` читает `server`, `email`, `path` и `key-type` из собственного набора флагов.

Перенос одного флага решал одну ошибку за прогон, потому что клиент сообщает только про первый нераспознанный флаг. Чтение исходника закрыло вопрос целиком.

## Вывод Для Работы

Когда инструмент отвергает аргумент, дешевле прочитать его определение флагов, чем переносить аргументы по одному. Каждая догадка здесь стоила создания ноды.
