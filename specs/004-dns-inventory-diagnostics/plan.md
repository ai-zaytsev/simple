# Plan: DNS Inventory Diagnostics

- Feature ID: `004-dns-inventory-diagnostics`
- Feature Branch: `feature/004-dns-inventory-diagnostics`
- Owner: `orchestrator`

## Implementation Slices

1. Разделить проверку учётных данных и вердикт.
2. Добавить вторую пробу Cloudflare через `zones`.
3. Добавить очистку пробельных символов и диагностические подсказки.
4. Смержить, запустить, разобрать фактическое состояние.

## Risks

- очистка пробелов может замаскировать по-настоящему неверное значение: в лог выводится отметка о том, что пробелы были найдены
- диагностические подсказки перечисляют вероятные, а не установленные причины: точную причину знает только владелец токена

## Validation Plan

- YAML-валидация, проверка ASCII
- запуск после merge и сверка с ожидаемым распределением доменов

## Merge Readiness

Задача закрывается, когда запуск показывает состояние обоих провайдеров независимо от того, работает ли каждый из них.
