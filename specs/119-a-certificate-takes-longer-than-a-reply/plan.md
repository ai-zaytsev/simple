# Plan: A Certificate Takes Longer Than A Reply

## Порядок

1. Найти, чей предел сработал, по времени запроса.
2. Продлить его для одного обработчика, не для сервиса.
3. Продлить предел прокси на том же пути, с запасом над сервисом.
4. Проверить, что предел агента и так больше обоих.

## Риски

**Ослабить сервис целиком.** Продлевается один обработчик через дедлайн ответа, а не `WriteTimeout` сервера.

**Прокси оборвёт раньше сервиса.** Поэтому 180 секунд против 120: тот, кто ждёт снаружи, должен пережить того, кого ждёт.

**Повиснуть навсегда.** Два предела вместо бесконечности; нода повторит на следующем круге.

## Валидация

- сборка проходит шаг сертификата
