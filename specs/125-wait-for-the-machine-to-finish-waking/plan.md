# Plan: Wait For The Machine To Finish Waking

## Порядок

1. Дождаться конца первого запуска.
2. Дать apt ждать блокировку самому.

## Риски

**Ждать вечно.** Оба ожидания ограничены пятью минутами.

**`cloud-init` отсутствует.** Проверяется наличие; без него остаётся второй рубеж.

## Валидация

- сборка проходит установку пакетов на свежесозданной машине
