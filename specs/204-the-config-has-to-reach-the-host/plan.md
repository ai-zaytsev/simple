# Plan: Конфигурация должна доезжать до хоста

## Порядок

1. Прочитать шаг за шагом, что сделает выкат на живом хосте.
2. Добавить `nginx.conf` в загрузку, с проверкой непустоты.
3. Заменить условие certbot на безусловный запуск с `--reinstall`.
4. Свести `server_name` к одному имени.

## Риски

**certbot падает — сайт остаётся без HTTPS.** Закрыто существующей ловушкой: при ошибке скрипт возвращает сохранённую конфигурацию и выкат падает громко.

**Лимит Let's Encrypt.** Пять одинаковых сертификатов в неделю. `--reinstall` при действительном сертификате не перевыпускает, поэтому обычный выкат лимит не трогает.

**Обрезанная загрузка обнулит конфигурацию.** `test -s` перед установкой, как и для четырёх файлов содержимого.

**Старый домен перестанет обслуживаться.** Осознанно и названо в границах.

## Валидация

`bash -n` на скрипте. Guard'ы сайта проходят. Настоящая проверка — сам выкат: если сертификат для нового имени не выпустится, шаг упадёт, а не притворится успешным.
