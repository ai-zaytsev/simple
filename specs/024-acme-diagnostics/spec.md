# Spec: Capture ACME Client Output

- Feature ID: `024-acme-diagnostics`
- Feature Branch: `feature/024-acme-diagnostics`
- Status: `in-progress`

## Проблема

Bring-up дошёл до выпуска сертификата и остановился на `certificate-failed` в ту же секунду, в которую был установлен ACME-клиент. Мгновенный отказ означает ошибку до обращения к серверу, но сам вывод клиента никуда не записывался.

Это делает следующую итерацию гаданием, а каждая итерация стоит ноды.

## Решение

Вывод ACME-клиента пишется в файл, и при отказе последние строки попадают в файл статуса. Доступа по SSH из прогона нет, поэтому единственный способ увидеть ошибку — опубликовать её там, где прогон уже читает.

Дополнительно в статус попадает код возврата, а шаг ожидания при отказе перечитывает файл заново: диагностика часто дописывается после того опроса, который заметил отказ.

## Правило

**Шаг, который может отказать без свидетеля, обязан оставлять свидетельство.** Особенно там, где повтор стоит создания ресурса.

## Acceptance Criteria

- при отказе выпуска сертификата в статусе виден вывод клиента

## Validation

- фактический прогон
