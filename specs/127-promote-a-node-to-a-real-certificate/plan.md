# Plan: Promote A Node To A Real Certificate

1. Записать, кто certifies ноду.
2. Попросить агента спросить сейчас.
3. Прочитать с провода, что она отдаёт.

**Счесть успехом запись в базе.** Итог судится по живому рукопожатию.
