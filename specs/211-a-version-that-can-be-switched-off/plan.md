# Plan: Версия, которую можно выключить

## Порядок

1. Поднять номер версии.
2. Мердж, затем `Publish APK` с подтверждением.
3. Сверить панель и `releases.json` с тем, что опубликовано.
4. Проверка на устройстве: обновление ставится, OFF выключает.

## Риски

**Пропуск в `versionCode`.** Публикация требует следующий номер, а не любой больший. 2 → 3.

**Публикация не с `main`.** Workflow отказывается собирать из чего-либо другого; поэтому сначала мердж.

**Считать выпуск законченным по зелёному workflow.** Опубликовано — это когда Core отдаёт новую версию, а файл по ссылке совпадает с записанным SHA-256. Проверяется после, а не предполагается.

## Валидация

Android Build на PR. После публикации — `Read The Panel` и чтение `releases.json`. Последнее слово за устройством: обновление должно поставиться поверх 0.1.1 тем же сертификатом.
