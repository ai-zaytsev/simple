# Plan: A Letter That Actually Opens

## Порядок

1. `withRecording` возвращает список писем, по одному на найденное почтовое приложение.
2. Приложения находятся `queryIntentActivities` по `ACTION_SENDTO` + `mailto:` — тому интенту, который здесь уже работает.
3. Экран: одно — открыть; несколько — системный выбор из них же.
4. Пустой список или исключение — видимый ответ, запись цела.
5. Три кнопки в одной колонке.

## Риски

**Отказ снова станет тихим.** Это и был главный дефект. Тест требует, чтобы отправка возвращала исход и чтобы экран на него реагировал.

**В списке появится мессенджер.** Он не может: письма адресованы по имени пакета, полученному из `mailto:`-запроса. Тест требует и запроса, и `setPackage`.

**`<queries>` окажется мало.** Объявлен `ACTION_SENDTO` + `mailto`, и именно им идёт запрос — то есть видимость ровно та, что уже подтверждена работающей кнопкой поддержки.

## Валидация

Только на телефоне. Предыдущая версия прошла сборку, тесты и обзор — и не открыла ничего; отсюда это неотличимо.
