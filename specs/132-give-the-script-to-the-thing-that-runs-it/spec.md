# Spec: Give The Script To The Thing That Runs It

Осмотр ноды отработал, вернул ноль и **не напечатал ничего**.

Причина: `ssh-retry.sh` берёт ввод из файла, названного в `SSH_STDIN`, и всё остальное перенаправляет из пустоты. Скрипт, поданный ему через heredoc, был молча выброшен, `bash -s` прочитал ничего и успешно ничего не сделал.

## Контракт, Который Я Сам Знал

`SSH_STDIN` существует не для красоты: неявный ввод однажды оставил запуск висеть на незакрытой трубе, и явное имя файла — это то, чем ту беду закрыли.

Я воспользовался инструментом, не соблюдя его условие, и получил самый неприятный вид отказа: успешный.

## Что Сделано

Скрипт пишется в файл, файл называется. То есть условие соблюдается, а не обходится.
