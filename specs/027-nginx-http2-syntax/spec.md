# Spec: Nginx HTTP2 Syntax

- Feature ID: `027-nginx-http2-syntax`
- Feature Branch: `feature/027-nginx-http2-syntax`
- Status: `in-progress`

## Достигнутое Состояние

Сертификат выпущен. Вся цепочка bring-up проходит: swap, пакеты, Nginx на 80, Xray, определение адреса, ожидание DNS, установка ACME-клиента, выпуск сертификата.

Отказ остался на последнем шаге: `nginx -t` отвергает TLS-конфигурацию.

## Причина

Директива `http2 on;` появилась в nginx 1.25. Ubuntu 24.04 поставляет 1.24, где HTTP/2 включается параметром директивы `listen`. Незнакомая директива делает недействительной всю конфигурацию.

## Решение

HTTP/2 включается параметром `listen`.

Дополнительно вывод `nginx -t` при отказе попадает в статус — тот же приём, который на предыдущем шаге сразу назвал причину отказа ACME-клиента вместо ещё одного круга догадок.
