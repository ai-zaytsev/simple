# Plan: Second Node

2. Создать вторую машину.
3. Расходный домен на неё, сертификат, nginx и Xray — тем же способом, что и первую.
4. Зарегистрировать в базе Control Plane.
5. Убедиться, что план теперь содержит непустой список резервов.

7. Показать возврат: вернуть первую, снова проверить.

Расходные домены израсходовали часть недельного лимита сертификатов при отладке Стадии 2. Если лимит упрётся, ждать сутки или взять домен из запаса у другого регистратора.
