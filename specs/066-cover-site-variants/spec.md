# Spec: Cover Site Variants

Стадия 10. Из требований выполнялось всё, кроме одного — и это одно проверено, а не предположено.

## Что Уже Работало

| Требование | Как было |
| --- | --- |
| Свой домен | `6015874.xyz`, `6015875.xyz` |
| Настоящий сертификат | Let's Encrypt, `CN` совпадает с доменом |
| Браузер видит настоящий сайт | 200, читаемая страница |
| Ни слова про продукт | Проверено поиском по файлам |
| Порт 80 ведёт на HTTPS | 301 |
| Неверный запрос к пути туннеля не выдаёт туннель | 404 |
| Сканирование выглядит обычным | Обычный `nginx`, обычные коды |

## Что Не Работало

**Страницы на двух нодах были побайтово одинаковыми.** Хэш совпадал: `093cba82a144` и там, и там. Посчитал контрольную сумму — и вот список наших доменов, одной командой.

Требование было записано в документации сайта ещё раньше и не выполнено. Документ описывал, как должно быть, а машины делали иначе — расхождение, которое видно только если посмотреть на машины.

## Что Изменено

Три варианта вместо одного: голуби, закрытые трамвайные линии, домашняя закваска.

Отличаются **целиком**, а не подставленным заголовком: другая тема, вёрстка, шрифт, структура разметки, стиль текста. Подстановка заголовка в общий шаблон оставила бы одинаковыми CSS, структуру и формулировки — то есть всё, по чему страницы группируются, кроме первой строки.

Страницы ошибок тоже свои. Одинаковая страница 404 на разных сайтах — тот же самый признак, только менее заметный.

## Проверено

| | `6015874.xyz` | `6015875.xyz` |
| --- | --- | --- |
| Заголовок | Городские голуби | Трамвайные маршруты |
| Хэш главной | `093cba82a144` | `97fbf79b6771` |
| Размер | 8411 байт | 6931 байт |
| Порт 80 | 301 на HTTPS | 301 на HTTPS |
| Путь туннеля из браузера | 404, 1041 байт | 404, 731 байт |
| Случайный несуществующий путь | 404, 1041 байт | 404, 731 байт |
| Переход на WebSocket | **101** | **101** |

Строки про путь туннеля и случайный путь совпадают **внутри каждой ноды** — код и размер одинаковые, отличить нельзя. И различаются **между нодами**, потому что у каждой своя страница ошибки.

Последняя строка — вторая половина требования: сайт настоящий, и туннель при этом работает.

## Что Не Является Защитой

Связать домены можно и другими способами: по времени выпуска сертификатов, по соседству адресов, по поведению. Смысл не в том, чтобы это стало невозможно, а в том, чтобы не делалось сравнением хэшей.
