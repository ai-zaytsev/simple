# Plan: One Letter, Or A File You Keep

## Порядок

1. `SupportMail.fill` — одна функция для адреса, темы и тела.
2. `SupportMail.withRecording` — `ACTION_SEND` с вложением и `mailto:`-селектором.
3. Экран: отправка идёт через него; общий диалог «поделиться» убран.
4. Сохранение через системный выбор места.
5. Удаление записи привязано к успеху каждого пути по отдельности.

## Риски

**Тексты разойдутся.** Самый вероятный и самый тихий: правят одно письмо, второе остаётся прежним. Закрыто одной функцией и тестом на число вхождений.

**Селектор потеряется.** Тогда файл со списком посещённых адресов снова окажется в одном касании от мессенджера. Тест требует строку селектора дословно.

**Запись исчезнет при неудаче.** Разные пути — разные условия: письмо открылось; копия удалась. Тест требует проверки «открылось».

**Почтового приложения нет.** Тогда ничего не откроется и запись останется. Кнопка поддержки для этого случая уже показывает адрес; здесь достаточно того, что ничего не потеряно.

## Валидация

Business Owner отправляет запись письмом и сохраняет её на устройство. Оба пути — на живом телефоне: именно здесь предыдущая версия и провалилась, пройдя все проверки.
