# Plan: One Log Button At A Time

## Порядок

1. Обычный лог не предлагается, пока нечего отправлять.
2. Названия разводятся так, чтобы их нельзя было перепутать.
3. Отключённая кнопка записи объясняет, почему отключена.
4. Диагностика среза убирается вместе с тем, что жило только ради неё.

## Риски

**Убрать нужное вместе с ненужным.** `BridgeDiagnostics` оставлен: он пишется в обычный лог при завершении сессии и там полезен. Удалены только те два класса, которые не использовал никто, кроме убранного блока.

**Название снова сойдётся.** Закреплено тестом, читающим `strings.xml`.

## Валидация

- Тест падает, если две подписи совпадут или начнут отличаться только окончанием.
- Сборка проверяет, что удалённые классы действительно никому не были нужны.
- Экран — глазами на устройстве.
