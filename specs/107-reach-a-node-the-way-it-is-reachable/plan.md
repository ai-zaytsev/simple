# Plan: Reach A Node The Way It Is Reachable

## Порядок

1. Подтвердить причину по правилам брандмауэра, а не по догадке.
2. Провести все обращения через Control Plane.
3. Назвать переход один раз на задание.

## Риски

**Забыть переход в одном шаге.** Такой шаг не упадёт, а зависнет. Поэтому адрес перехода объявлен один раз.

**Ключ хоста ноды неизвестен раннеру.** Просканировать его нельзя — порт закрыт, — поэтому принимается при первом соединении, как и при создании ноды.

- живой запуск доходит до установки
