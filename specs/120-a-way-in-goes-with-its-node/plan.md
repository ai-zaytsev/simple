# Plan: A Way In Goes With Its Node

## Порядок

1. Выключить записи входа в том же операторе, где снимается нода.
2. Записать это как инвариант, а не как удаление конкретной строки.
3. Показать, сколько путей входа осталось.

## Риски

**Выключить настоящую точку входа.** Условие ограничено `https-edge` — записями, которые форвардят API ноды. Точка входа Control Plane не форвардит ничего.

**Оставить прежние хвосты.** Инвариант чинит их при первом же следующем сносе.

## Валидация

- после сноса домен принимается `Add Server`
- число включённых путей входа печатается и совпадает с ожиданием
