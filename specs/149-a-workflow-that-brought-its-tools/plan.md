# Plan: A Workflow That Brought Its Tools

## Порядок

1. Вернуть `Checkout` в `purchases.yml`.
2. Написать проверку.
3. Испытать её на настоящей ошибке, а не на предположении.
4. Встроить в baseline.

## Риски

**Проверка не заметит другой способ вызова.** Ищутся запуски из `.github/scripts/`, `infra/`, `node/`. Расширять на любую строку с `python3` значило бы ловить встроенные скрипты и требовать checkout там, где он не нужен.

**Ложное срабатывание.** Workflow, у которого checkout есть по другой причине, проходит — проверка требует наличия, а не порядка.

## Валидация

Не «скрипт запускается»: шаг удалён из живого файла, проверка его нашла, шаг возвращён.
