# Plan: A File Every Application Accepts

## Порядок

1. Имя выгрузки — `.txt`; старое имя остаётся в очистке.
2. Кодировка выгрузки названа явно.
3. `ClipData` в интенте отправки.
4. Тесты по исходнику на все три.

## Риски

**Расширение вернут обратно.** Тогда всё повторится, и повторится тихо: интент по-прежнему будет объявлять `text/plain`, и вина будет выглядеть чужой. Тест требует `.txt` прямо в константе.

**Старый файл останется в кеше.** Он недостижим с экрана и будет тем файлом, который кто-то найдёт позже и не поймёт. Удаляется по прежнему имени.

**`ClipData` сочтут лишним.** Он не про тип, а про грант, и его отсутствие даёт пустое вложение вместо отказа — то есть отказ, который выглядит успехом.

## Валидация

Не «собирается»: Business Owner отправляет лог через мессенджер и через почтовый клиент, и оба принимают.
