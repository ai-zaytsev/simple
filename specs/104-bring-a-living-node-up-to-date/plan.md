# Plan: Bring A Living Node Up To Date

## Порядок

1. Взять механизм у тех, кто уже ходит на ноды: `add-node.yml` и `lifecycle.yml`. Не изобретать заново.
2. Адрес — из базы по алиасу.
3. Откат вооружить до копирования.
4. Установить, осмотреть, снять откат.

## Риски

**Запереть себя на ноде.** Шейпер трогает входящее направление целиком. Откат вооружается до изменения и снимается только после осмотра.

**Обновить не ту машину.** Адрес спрашивается у базы по алиасу, а не вводится.

**Уронить весь флот разом.** По одной ноде за запуск, по имени.

**Счесть здоровой по коду возврата.** Осматриваются службы, ответ веб-сервера и проверка приватности.

## Валидация

- первая нода обновлена и осмотрена, вторая после неё
- после обновления — панель против ожидания
