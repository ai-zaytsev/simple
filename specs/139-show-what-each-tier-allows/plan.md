# Plan: Show What Each Tier Allows

## Порядок

1. `tierPolicies` в overview: читает `tier_limits` и считает аккаунты на каждом тарифе.
2. Пределы — указатели, чтобы `null` доехал до панели как `null`, а не как число.
3. Текстовое чтение панели: раздел «Что даёт тариф», `limit()` для трёх ответов.
4. HTML-панель: тот же раздел, `ceiling()` для тех же трёх.
5. Фикстуры получают строки тарифов; baseline проверяет обе крайности.

## Риски

**Число вместо «без предела».** Самый дорогой исход: тариф, который освободили, выглядит ограниченным, и это заметят на первом покупателе. Закрыто проверкой baseline на строке VIP целиком.

**Ноль как безлимит.** Обратная ошибка, и она врёт про FREE. Закрыто такой же проверкой на строке FREE.

**Пустой раздел на свежем развёртывании.** `tiers` может не прийти; текстовое чтение пропускает раздел, HTML печатает пустую таблицу. Фикстура `overview-empty.json` намеренно оставлена без тарифов, чтобы этот путь проходили.

## Валидация

Baseline рендерит фикстуры и **смотрит на вывод**, а не только на то, что скрипт не упал. Разница между этими двумя проверками уже однажды стоила неверно прочитанного домена.

После выката — панель, и на ней должно быть видно: FREE 1 / нет / 10 Мбит/с, VIP без предела трижды. Это и есть ответ на вопрос, который до сих пор был утверждением про файл.
