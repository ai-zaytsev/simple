# Plan: TUN Bridge

- Feature ID: `031-tun-bridge`
- Feature Branch: `feature/031-tun-bridge`
- Owner: `orchestrator`

## Implementation Slices

1. Снять контракт с исходников закреплённой версии.
2. Go-обёртка с поверхностью из трёх функций.
3. Сборка через gomobile, встроенная в сборку приложения с кэшем.
4. Связка с сервисом, включая передачу владения дескриптором.
5. Сборка APK.

## Risks

- gomobile собирает под конкретные архитектуры: выбраны arm64 и amd64, первая для телефонов, вторая для эмулятора
- размер APK заметно вырастет: внутри две нативные библиотеки
- поведение при смене сети проверяется только на устройстве

## Validation Plan

- сборка APK в CI с обеими библиотеками
- проверка на устройстве после сборки с рабочей точкой входа

## Merge Readiness

Закрывается зелёной сборкой, где в отчёте видны и движок, и переходник.
