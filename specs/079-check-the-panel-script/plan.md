# Plan: Check The Panel Script

## Порядок

1. Извлечь скрипт из страницы и разобрать.
2. Проверить в обе стороны на настоящей опечатке.
3. Поставить в общую проверку сборки.

## Риски

**Проверка, написанная согласиться с кодом.** Закрыто тем, что она проверена на реальной ошибке, а не на выдуманной.

**Ложное срабатывание из-за расширения файла.** Node отказывается разбирать файл без знакомого расширения, и отказ читается как синтаксическая ошибка. Временный файл назван `panel.js`.

## Валидация

- С подставленной опечаткой — падает и называет строку.
- Без неё — проходит.
