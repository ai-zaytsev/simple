# Spec: Check The Panel Script

Панель — один встроенный HTML-файл без сборки и без тестового окружения. Опечатка в нём доезжает до сервера.

## Почему

Одна уже доехала: посреди списка аргументов остался ярлык `challenge:`, и страница не отрисовывалась вообще. Нашёл я это тем, что открыл её в браузере и заметил пустоту. Это везение, и на следующую правку оно не распространяется.

С тех пор я правил этот файл ещё дважды через `perl`, и оба раза проверял результат глазами.

## Что Проверяется

Только синтаксис: скрипт извлекается из страницы и разбирается `node --check`. Сказать, показывает ли панель правильные числа, это не может — для этого по-прежнему нужно посмотреть. Но каждая пойманная ошибка — та, которую иначе нашёл бы человек, открывший панель и увидевший пустой экран.

Проверено в обе стороны: подставил ту самую опечатку — падает с указанием строки; вернул — проходит.

## Мелочь, Стоившая Отдельного Комментария

`node` выбирает способ разбора по расширению файла и отказывается разбирать файл без знакомого расширения. Отказ выглядит ровно как синтаксическая ошибка и ею не является. Временный файл поэтому называется `panel.js`.

## Границы

Отсутствие `node` не роняет проверку, а пропускает её: на машине разработки его может не быть, и падение по этой причине научило бы игнорировать результат.
