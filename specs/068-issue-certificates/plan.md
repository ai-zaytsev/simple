# Plan: Issue Certificates

1. Редактор DNS-записи для обоих регистраторов.
2. Выпуск по CSR через ACME с проверкой владения по DNS.
3. Учёт выпусков и отказов против недельного предела.
4. Агент на ноде: ключ, запрос, проверка соответствия, установка, перезагрузка.
5. Ежедневный таймер с разбросом.

## Риск

Первый настоящий выпуск тратит одну единицу недельной квоты. Поэтому порядок такой: сначала проверена запись в DNS, потом код, и только потом выпуск на живой ноде.
