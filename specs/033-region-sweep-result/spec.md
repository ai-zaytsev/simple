# Spec: Region Sweep Result

## Зачем

Записать результат перебора регионов DigitalOcean, чтобы он не проверялся заново и чтобы решение по площадке опиралось на цифры.

## Что Измерено

По одной машине в шести регионах, каждая отдаёт один и тот же файл в 5 МБ. Замер из российской сети, окно 30-45 секунд.

## Scope

- `network-path.md` — таблица результатов и признак, по которому это узнаётся
- `ADR-029` — уточнение: ограничение не региональное
