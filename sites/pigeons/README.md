# Cover Site

Одностраничный сайт, который открывается на entry-домене при обычном HTTPS-запросе. Тема выбрана Business Owner: городские голуби.

## Зачем он такой

Заглушка выдаёт себя сразу. Страница с надписью «сайт в разработке» на домене, к которому кто-то держит долгоживущее TLS-соединение, — это подтверждение, что домен служебный, а не прикрытие.

Поэтому страница написана как настоящие любительские заметки: с содержанием, которое можно прочитать, и без признаков генерации.

## Технические требования, которым страница подчиняется

**Ни одного внешнего запроса.** Ни шрифтов, ни аналитики, ни картинок с других хостов. Три причины: нода остаётся самодостаточной, посетитель сайта не утекает третьим сторонам, и у страницы нет исходящих соединений, по которым её можно связать с другими нашими доменами.

**Никаких упоминаний продукта.** Сайт не должен быть связан с VPN-сервисом ничем: ни текстом, ни ссылками, ни метаданными.

**Статика без зависимостей.** Один файл, встроенный CSS. Nginx отдаёт его без интерпретации.

## Различие между доменами

Одинаковый файл на четырёх доменах делает их одной группой при простом сравнении содержимого. Перед раскаткой на каждый домен подставляются свои заголовок и вводный абзац, чтобы совпадение не было побайтовым.

Это не защита, а снижение стоимости ошибки: связать домены всё равно можно другими способами, но не тривиальным сравнением хэшей.
