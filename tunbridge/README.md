# TUN Bridge

Переходник между сетевым интерфейсом Android и локальным прокси, который поднимает транспортный движок.

## Зачем он существует

Движок говорит по SOCKS на петлевом адресе и ничего не знает про интерфейс устройства: в его исходниках нет ни одной строки про TUN. Без этого пакета приложение устанавливает соединение с нодой, но трафик устройства до неё не доходит.

## Владение дескриптором

Дескриптор переходит во владение переходника. Вызывающая сторона отсоединяет его от Java-владельца перед передачей, иначе он был бы закрыт дважды: один раз Java, второй раз Go.

Освобождает дескриптор `Stop`.

## Почему поверхность из трёх функций

Через границу gomobile проходят только простые типы. Узкую поверхность проще удержать правильной, чем полную.

## Сборка

Собирается в CI тем же способом, что и движок: из исходников, с закреплённой версией зависимости. Смотрите `ADR-020` и workflow сборки приложения.
